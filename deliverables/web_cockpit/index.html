About This Project & Limitations

What this demonstrates

An end-to-end FP&A / strategic-finance workflow built entirely from public SEC filings: extracting and validating historical financial facts (including catching a real, undisclosed-in-summary segment-expense reclassification), building a scenario-based operating forecast with an explicit information cutoff, deriving an investment-capacity and capital-allocation framework with proven no-double-counting checks, running a restrained DCF valuation, and presenting all of it through an auditable, reproducible pipeline — a database, an Excel model, a Power BI handoff package, and this web cockpit.

What this is not

Not investment advice, not a price target, not a claim of insider or non-public information, and not a prediction — every figure past FY2025 is a labeled scenario assumption, and every one of them is documented and reproducible from the source filings in docs/sources.csv.

Known limitations

    Built from 8 registered SEC filings (10-K/10-Q), information cutoff . Not investment advice. See docs/ for full methodology, validation, and lineage.
