Investment Capacity — Corrected Taxonomy

This is the differentiating feature of the project. Every component below is labeled as a STOCK, FLOW, SOURCE, USE, or RESERVE — never blended. Debt-funded capacity is never combined with self-funded capacity: new borrowing is not internally generated operating cash.

Why this matters

A single "deployable capacity" number that mixes an opening cash stock, this year's generated cash, new borrowing, and money already spent is not one thing — it cannot be compared across scenarios or years without knowing which of those four ingredients moved. This taxonomy keeps them separate so a reviewer can see why a number changed, not just that it did.

FY2030, selected scenario. Source/use waterfall — see the full five-year reconciliation below.

Known limitations

What this demonstrates

An end-to-end FP&A / strategic-finance workflow built entirely from public SEC filings: extracting and validating historical financial facts (including catching a real, undisclosed-in-summary segment-expense reclassification), building a scenario-based operating forecast with an explicit information cutoff, deriving an investment-capacity and capital-allocation framework with proven no-double-counting checks, running a restrained DCF valuation, and presenting all of it through an auditable, reproducible pipeline — a database, an Excel model, a Power BI-ready handoff package, and this web cockpit.

What this is not

Not investment advice, not a price target, not a claim of insider or non-public information, and not a prediction — every figure past FY2025 is a labeled scenario assumption, and every one of them is documented and reproducible from the source filings in docs/sources.csv.
